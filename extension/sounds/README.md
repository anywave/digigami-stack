# DIGIGAMI Guardian Sound Effects

This directory contains audio files for DIGIGAMI Guardian notifications and interactions.

## Required Sound Files

- `notification.mp3` - Played when content is blocked or a notification is shown
- `panic.mp3` - Played when panic mode is activated
- `success.mp3` - Played when bypass is granted
- `denied.mp3` - Played when bypass is denied

## Sound Design Guidelines

- Keep sounds short (< 1 second for notifications)
- Use calm, non-jarring tones
- Match the meditative/mindful theme of DIGIGAMI
- Suggested: Soft chimes, gentle bells, or subtle synth tones

## Free Sound Resources

- https://freesound.org/ - Search for "notification chime" or "gentle bell"
- https://mixkit.co/free-sound-effects/ - Free sound effects library
- https://pixabay.com/sound-effects/ - Royalty-free sounds

## File Format

Use MP3 format for best browser compatibility. Keep file sizes small (< 50KB each).
